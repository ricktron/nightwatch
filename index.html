About NightWatch

NightWatch is a personal software project developed and operated by Rick Garnett. It brings together selected tools and third-party services to support private workflows, analysis, and automation.

NightWatch is not a public software service and is not offered for sale.

Yahoo Fantasy Sports integration

NightWatch includes a private fantasy football feature for two Yahoo Fantasy Football leagues in which I participate, including a league I administer as commissioner.

The integration is intended to use the read-only Yahoo Fantasy Sports API for league settings, teams, managers, rosters, players, standings, matchups, scoring, transactions, and related historical analysis.

Yahoo Fantasy Sports data is used only for private league analysis, weekly summaries, matchup and roster analysis, historical tracking, and commissioner assistance. NightWatch does not sell or redistribute Yahoo Fantasy Sports data and does not provide a public fantasy sports service.

Data and privacy

Access to fantasy league data is limited to the personal use described above. The project requests read-only access and does not require write access to Yahoo Fantasy Sports.

Yahoo and Yahoo Fantasy Sports are trademarks of Yahoo. NightWatch is an independent personal project and is not affiliated with or endorsed by Yahoo.
